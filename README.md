# PhishGuard — Desktop UI

A dark cyberpunk-themed desktop application for phishing detection.

## Setup & Run

```bash
pip install -r requirements.txt
python app.py
```

## Requirements
- Python 3.9+
- Internet connection (for DNS/SSL/fetch analysis)

## Features
- Modern dark desktop GUI (CustomTkinter)
- Real-time animated scanning loader
- Risk score display with color coding
- Filter findings: ALL / FAILED / WARNINGS / PASSED
- Domain info panel (host, domain, protocol)
- Open scanned URL in browser
- Status bar with live feedback
